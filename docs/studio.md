# 가이드 제작 도구 사용법 (`studio/`)

캡처 이미지와 문구만 있으면 `guide.json` + 이미지 폴더 + 뷰어가 묶인 **배포용 zip** 이 나옵니다. 설치·서버 불필요, 브라우저에서만 동작합니다.

## 열기
- 저장소를 웹 서버로 연 뒤 `…/studio/` 로 접속합니다. (GitHub Pages: `https://mk-jeon.github.io/eformsign/studio/`)
- 파일로 직접 열면(file://) 미리보기와 뷰어 파일 포함이 동작하지 않습니다.

## 순서
1. **가이드 정보** — ID(폴더명·URL 경로), 브랜드, 제목, 표지·종료 문구, 자동재생 초, 강조색.
2. **단계 추가** — 「이미지로 단계 추가」로 캡처 여러 장을 한 번에 선택(파일명 순 정렬) 하거나 가운데 화면에 끌어다 놓습니다. 이미지는 폭 810px JPEG 로 자동 변환됩니다.
3. **단계마다** 구간(같은 이름끼리 묶임) · 제목 · 설명 · 주의 문구를 적습니다.
4. **강조 박스** — 도구에서 「강조 박스」를 고르고 이미지 위를 드래그. 라벨을 적고, 넓은 영역이면 「부드럽게」.
   - 「블러(개인정보)」 박스는 화면에서 흐리게 보이고, 내보낼 때 이미지 자체에도 픽셀화됩니다.
   - 「탭 위치」는 클릭한 곳에 눌러야 할 지점 애니메이션이 표시됩니다.
   - 박스는 드래그로 이동, 모서리로 크기 조절, Delete 키로 삭제.
5. **미리보기** — 오른쪽에 실제 뷰어가 실시간으로 반영됩니다.
6. **내보내기** — `<ID>_guide_날짜.zip`. 안에 `<ID>/` 폴더(뷰어 + guide.json + assets)와 배포 안내문이 들어 있습니다. 이 폴더를 그대로 `guide.monki.net/<ID>/` 에 올리면 됩니다.

## 이어서 수정
- 작업 내용은 브라우저에 자동 저장됩니다(초안). 같은 브라우저로 다시 열면 이어서 작업할지 묻습니다.
- 다른 PC 에서 수정하려면 「불러오기」에서 `guide.json` 과 `assets/` 이미지들을 **함께 선택**합니다.

## 팁
- 단계 이미지는 같은 크기의 세로 캡처가 보기 좋습니다(휴대폰 전체 화면 캡처).
- 개인정보(이름·번호·주소)가 보이는 화면은 반드시 블러 박스를 그려 주세요. 공개 주소로 배포되므로 이미지에 남으면 그대로 노출됩니다.
